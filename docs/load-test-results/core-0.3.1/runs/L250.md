## 8. Data quality / caveats

- Histogram percentiles are bucket upper bounds, not exact percentiles.
- Accepted lines count acknowledgements (includes replay after restart; not unique DB rows).
- Producer `delivered` counts messages; use `total_points` for point totals.
- Core VM memory used % peaked at 82% during steady while CPU stayed ~22%; monitor before stepping to L350.
- Telemetry scaled to **0** instances for part of the generation window — UI/subscriber load not exercised by Cloud Monitoring request metrics during peak ingest.
