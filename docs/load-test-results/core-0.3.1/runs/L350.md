## 8. Data quality / caveats

- Steady metrics exclude the first 60 s and use 60 s Core publication intervals; network rates derived from cumulative `interface/traffic` deltas on `ens3` (loopback excluded).
- Persistence percentiles are histogram bucket upper bounds, not exact batch percentiles.
- `[Summary] sent_pts_s=69,995` per process is the 600 s average (≈70,000 pts/s), not the harness steady-rate estimator.
- Generator host NTP: `clock.txt` shows sub-ms VM offsets; generator `before` chrony ~0.2 ms slow of NTP.
